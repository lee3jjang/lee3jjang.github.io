# lee3jjang.github.io

이상진의 개인 소개 페이지와 블로그입니다. GitHub Pages(Jekyll)가 자동으로 빌드합니다.

- 주소: https://lee3jjang.github.io
- `index.html`: 메인 프로필
- `kodebox.html`: 코드박스(ZUZU) 경력 상세
- `dbinsurance.html`: DB손해보험 경력 상세
- `blog/`: 블로그 목록. 글은 `_posts/YYYY-MM-DD-slug.md`에 마크다운으로 추가 (형식은 `_drafts/example.md` 참고)
- 아직 채울 내용은 HTML 안에 `TODO` 주석으로 남겨 두었습니다.
- 로컬 미리보기: `jekyll serve` 실행 후 http://localhost:4000 접속
